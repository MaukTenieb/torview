L'exécution, ligne à ligne

Cliquez ▶ ci-dessus : la sortie console d'une exécution réelle de torview.exe --smoke sera rejouée ici, comme dans un terminal.

Ce que vous voyez : le journal authentique d'une exécution réelle (Windows 11 x64, Tor 15.0.24 officiel). Un navigateur ne peut pas exécuter un binaire Windows — cette relecture en déroule la sortie réelle ; le bouton ⬇ l'exécute pour de vrai chez vous, et torview.exe --smoke la recopie sur votre machine (code 0 exigé).

Ce que fait TorView

  • Démon Tor officiel embarqué (torproject.org, SHA-256 vérifié contre les sommes signées), ports aléatoires, authentification SAFECOOKIE, extinction propre — zéro orphelin.
  • DNS résolu côté Tor (SOCKSv5 remote-DNS) ; WebRTC désactivé couche Chromium + masque script ; profil éphémère par défaut : les cookies ne lient pas les sessions.
  • Fail-closed : pas de preuve → pas de fenêtre. Garde de transport : notre code ne peut plus toucher le réseau hors loopback.
  • Zéro dépendance exotique : client SOCKS5 audité de 168 lignes, un seul binaire Go.

⚠️ Lucidité assumée : TorView n'est pas Tor Browser — pas d'anti-fingerprinting (canvas, polices, horloge = ceux du moteur). Routé par Tor ≠ durci contre l'identification. Complément léger, pas remplaçant : lisez le README et SECURITY.md.
