TorView

Navigateur web minimaliste piloté par un démon Tor officiel — la fenêtre ne s'ouvre qu'après preuve que le trafic sort par un relais de sortie.

⬇ Télécharger TorView (Windows x64) Autres plateformes, sources et empreintes : la page Releases · code source

Ce que fait TorView

  • Démon Tor officiel embarqué, téléchargé chez torproject.org, SHA-256 vérifié contre les sommes signées ; ports aléatoires, authentification SAFECOOKIE, extinction propre (zéro processus orphelin).
  • DNS résolu côté Tor (SOCKSv5 remote-DNS) ; WebRTC désactivé à la couche Chromium et masqué par script ; profil éphémère par défaut — les cookies ne lient pas les sessions.
  • Preuve avant la fenêtre : relais de sortie confirmé (check.torproject.org via Tor), identity NEWNYM, aller-retour .onion réel — le tout dans le journal, reproductible via torview.exe --smoke.
  • Zéro dépendance exotique : client SOCKS5 audité de 168 lignes, un seul binaire.

Vérifier le zip téléchargé (Windows)

Chaque Release joint son empreinte (torview-windows-x64.zip.sha256) ; comparez :

certutil -hashfile TorView-0.6.0-windows-x64.zip SHA256

⚠️ Lucidité assumée : TorView n'est pas Tor Browser — pas d'anti-fingerprinting (canvas, polices, horloge = ceux du moteur). Routé par Tor ≠ durci contre l'identification. Utilisez-le en complément, lisez le README et SECURITY.md avant de faire confiance.
